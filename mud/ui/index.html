    Getting started

    A few things worth doing once for each character. Each ticks itself when it is done, and nothing is sent without a click.

    1. The world

      The map, the routes and the gag library come from 3kdb. The first run fetches them by itself; Options → Updates takes anything new.

    2. Save your own colours

      Before the next step, if you might go back to another client: the markers replace a few of your colour settings, and this keeps them so they can be put back.

    3. Line markers

      Markers let the client read 3K's room output reliably, so the map knows where you are about twice as often. You never see them. The first click shows what will be sent; the second sends it.

    4. Brief mode

      3K's own setting for short or long room descriptions, and its minimap. The client maps either way.

    5. If you like

      Hide spam with 3kdb's gags, walk with the numpad, and choose which tells and channels ding.

    Routes & bots

    Paths to walk and what to fight on the way. Start them here or from the Bot panel under the map.

    Deadman
    minutes without you typing

    Bots pause and nothing automated is sent until you type again. 0 turns it off.

    Folders

    Everything you have filed under one name, whatever kind it is. Put a folder name on a trigger, an alias, a timer or a route and it appears here.

    Triggers

    Run commands when the MUD sends a line that matches.

    Gags

    Lines kept off the screen: your own, and 3kdb's in groups that start off. Your triggers and the log still see what is hidden.

    Your gags

    The same as typing /gag: any line containing the text, capitals and all.

    From 3kdb

    Aliases

    A short word you type that stands for one or more commands.

    Events

    React to a tell, a channel line or a combat round. The client already knows who said what, so there is no pattern to write.

    Stat watches

    React when a number crosses a line — your health, spell points, or the enemy's health. Fires once, on the crossing.

    Timers

    Send something every so often.

    From the command box: /tick 290 xp makes one, /ticks lists them, and /delay 5 quaff heal sends something once.

    Script files

    Rules from Python files in the scripts folder. Edit the file to change one; it reloads when saved.

    Layout

    What is on screen. Saved in this browser, so another window can be set out differently.

    Show
    Terminal

    3K draws about 80 columns wide. A cap stops lines stretching across a wide window; it never affects a narrow one.

    Keyboard

    The command box and the numpad. Saved in this browser.

    Command box

    It stays selected: Enter sends it again, and typing anything replaces it.

    h j k l are nw, ne, sw and se; a step in brackets is any command, as in .2n(climb pipe)e. Only a line of nothing but moves walks; anything else is sent as typed.

    Numpad

    With text in the box the keys type numbers, unless this says always. Holding a key sends once.

    Any command, or several separated by ;. An empty key types its number.

    Sounds

    What each thing sounds like: the built-in chime, nothing, or a file of your own. Choose which lines ding by right-clicking them in the messages window.

    Sounds
    What plays

    Your own files are mp3, wav, ogg or m4a, up to 2 MB, and are kept with your map, not in the browser. Your own lines never ding, and nor does a channel you have hidden.

    Character setup

    Settings kept on your character in 3K, not in this client.

    Line markers

    If you go back to another client, the markers stay on your character. Save your colour settings first and you can put them back later.

    Brief mode

    3K's brief setting: one-line room titles instead of descriptions, and 3K's own minimap. This client draws its own map either way.

    Commands

    Client commands, typed in the command box. They never reach the MUD. Click one to put it in the box.

    From TinTin++, zMUD or CMUD

    Bring your aliases, triggers, gags, timers and paths across: pick your TinTin++ files, or zMUD's or CMUD's settings export, and see what each becomes before anything is added.

    Aliases, triggers, gags and timers come across, with %1 as {1}, a class as a group, #delay or #WAIT as a wait; a zMUD #PATH becomes a route, and a speedwalk its steps. Real TinTin++ programming — #if, #math, #foreach — does not; each is listed with the reason, so you can write it as a script instead.

    Help

    How to use the client, a topic at a time. The same guide is in the output: /help triggers, /help regex.

    Map & bot updates

    The map and the route library come from jmitchell33/3kdb. An update only adds — nothing you have walked, renamed or edited is changed.

    Only data is taken: the map, the named destinations and the bots. Your scripts are never touched.

    Fresh copy drops this client's copy of what is ticked and takes 3kdb's as it stands — for a map that has gone wrong, which an update cannot fix because an update only adds. It costs what you have added to those things: room names you set, visit counts, exits learned by walking, and 3kdb's own routes as you have edited them. Your own routes, and your session log, are kept.

    The walk

    Directions separated by spaces, commas, semicolons or new lines. 3n repeats a step. Anything that is not a direction is sent as a command — climb pipe, enter. Wrap a step in { } to keep something containing a separator together.

    Optional, and only for keeping the list tidy — it changes nothing about how the route walks. A / makes another level. The folder exists as long as something is in it, so naming one here is how you make it.

    The hunt

    A name, or any word from the long description — archangel catches all ten. Separate with commas. Leave blank to walk without fighting.

    New rule

    When

    All conditions must hold. Leave empty to fire every time the event happens.

    seconds

    Checked on the game's beat, so anything under two seconds is a number the client cannot keep. Nothing fires until MIP is flowing: before that the beat free-runs, and the login prompt is no place to send commands.

    Otherwise it fires on every update while the condition holds, and 3k.org sends two per combat round.

    Then

    A capture goes in with braces: {who}, {args}, {1}. A wait holds back everything below it for that many seconds.

    How

    Files it with everything else of that name — triggers, aliases, timers and routes alike — and they switch together: /group zodiacs on or /group zodiacs off, or the switch on the folder in . A / makes another level, as in zodiacs/hunting.
