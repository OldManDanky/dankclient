# The messages window

Tells, souls and channel lines, kept across the top where combat cannot scroll them away.

- **Tags** along the top, one per channel plus **tell** and **soul**: click one to hide it.
- **mine** hides what you said yourself.
- **clear** empties it. It asks first: click it twice.
- **Drag** its bottom edge to make it taller or shorter; double-click the edge to put it back.
- **Click** a line to put a reply in the command box.
- **Right-click** a line to colour every line on that channel or from that person, or to ding for them. See [Sounds](#sounds).
- **Hide** in the same menu keeps everything from that person out of this window. `/block <name>`, `/unblock <name>` (or `/unblock all`) and `/blocked` do the same from the command line, so an alias or a trigger can too. The main output still shows what they say.

A soul reads as 3K prints it: *From afar, Someone moos at you.*
